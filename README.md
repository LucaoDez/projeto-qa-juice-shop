
# OWASP Juice Shop

## Sobre o Projeto

Este repositório foi desenvolvido como parte de um trabalho acadêmico, com o objetivo de estudar e aplicar conceitos relacionados à segurança de aplicações web, utilizando o OWASP Juice Shop como ambiente de testes.

## Sobre o OWASP Juice Shop

O **OWASP Juice Shop** é uma aplicação web intencionalmente vulnerável, desenvolvida para fins educacionais e de treinamento em segurança da informação.

A plataforma simula uma loja virtual e apresenta diversas vulnerabilidades que permitem aos estudantes praticar técnicas de identificação, análise e compreensão de falhas de segurança em aplicações web.

O projeto é mantido pela OWASP (Open Worldwide Application Security Project), uma organização dedicada à melhoria da segurança de software.

Durante o desenvolvimento deste trabalho, serão realizados testes de segurança na aplicação, buscando identificar vulnerabilidades, compreender seus impactos e documentar os resultados obtidos.

## Objetivos

- Compreender os fundamentos da segurança em aplicações web;
- Identificar possíveis vulnerabilidades presentes na aplicação;
- Realizar testes de segurança em um ambiente controlado;
- Documentar as falhas encontradas e seus respectivos impactos;
- Desenvolver conhecimentos práticos sobre análise de segurança.
